# 📊 Análise de Marketing | Power BI

## 📌 Sobre o Projeto

Este projeto tem como objetivo analisar dados de clientes, comportamento de compra, desempenho de campanhas de marketing e canais de venda, utilizando o **Microsoft Power BI** para transformar dados em informações relevantes para a tomada de decisões estratégicas.

A análise foi desenvolvida a partir de uma base de dados com **2.000 registros de clientes e 27 colunas**, contendo informações demográficas, dados de consumo, histórico de compras, participação em campanhas e país de origem.

O projeto apresenta diferentes perspectivas do negócio por meio de um dashboard interativo, facilitando a identificação de padrões de consumo e oportunidades para aprimorar as estratégias de marketing.

## 🎯 Objetivos

* Analisar o perfil dos clientes com base em características demográficas e socioeconômicas.
* Investigar o comportamento de compra e os hábitos de consumo.
* Avaliar a participação dos clientes nas campanhas de marketing.
* Comparar os canais de compra utilizados pelos consumidores.
* Analisar os gastos por categoria de produto.
* Identificar oportunidades para melhorar o relacionamento com os clientes e direcionar ações de marketing.

## 🛠️ Ferramentas e Tecnologias

* **Microsoft Power BI:** desenvolvimento do dashboard e visualização dos dados.
* **CSV:** armazenamento e disponibilização da base de dados.
* **Análise de Dados:** exploração de variáveis relacionadas a clientes, consumo, campanhas e vendas.

## 📈 Análises Desenvolvidas

O dashboard está organizado em quatro páginas, cada uma dedicada a uma perspectiva da análise de marketing.

### 1. 👥 Visão Cliente

Análise das características dos clientes, considerando variáveis como:

* Escolaridade;
* Estado civil;
* Renda anual;
* Ano de nascimento;
* Quantidade de crianças e adolescentes em casa;
* País de origem.

**Objetivo:** compreender o perfil dos consumidores e identificar características relevantes para a segmentação de clientes.

### 2. 🛒 Visão Comportamento

Análise dos hábitos de consumo e das interações dos clientes com os canais de venda.

Entre as variáveis disponíveis estão:

* Gastos por categoria de produto;
* Quantidade de compras realizadas com desconto;
* Compras pela internet;
* Compras por catálogo;
* Compras em lojas físicas;
* Número de visitas mensais ao site;
* Dias desde a última compra.

**Objetivo:** compreender como os clientes compram, quais categorias de produtos representam seus gastos e quais canais fazem parte de sua jornada de consumo.

### 3. 🎯 Visão Campanha

Análise das respostas dos clientes às campanhas de marketing.

A base contém indicadores relacionados a cinco campanhas, além de uma variável que identifica se o cliente realizou uma compra.

**Objetivo:** explorar a adesão às campanhas, identificar padrões de resposta e apoiar a avaliação das estratégias de marketing.

### 4. 🏪 Visão Pontos de Venda

Análise relacionada aos canais de compra e à distribuição do comportamento de consumo.

A base permite investigar a utilização de diferentes canais, como internet, catálogo e lojas físicas, contribuindo para a compreensão das preferências dos clientes.

**Objetivo:** avaliar a participação dos canais de venda na jornada de compra e identificar oportunidades de aprimoramento da estratégia comercial.

O conjunto de dados permite explorar indicadores como:

| Indicador                | Descrição                                                  |
| ------------------------ | ---------------------------------------------------------- |
| Total de clientes        | Quantidade de registros de clientes na base.               |
| Salário anual            | Distribuição da renda anual dos clientes.                  |
| Gastos por categoria     | Valores gastos em diferentes categorias de produtos.       |
| Compras pela internet    | Quantidade de compras realizadas pela web.                 |
| Compras por catálogo     | Quantidade de compras realizadas por catálogo.             |
| Compras em lojas físicas | Quantidade de compras realizadas nas lojas.                |
| Compras com desconto     | Quantidade de compras realizadas com descontos.            |

| Visitas ao site          | Número de visitas mensais ao website.                      |

*Observação: os indicadores acima representam possibilidades de análise a partir das variáveis disponíveis na base. Os resultados quantitativos e as conclusões dependem das métricas e dos filtros aplicados no dashboard.*

## 💡 Aplicações de Negócio

A análise dos dados pode contribuir para:

* **Segmentação de clientes:** identificar grupos com características e comportamentos semelhantes.
* **Personalização de campanhas:** direcionar ações de marketing de acordo com o perfil dos consumidores.
* **Análise de canais:** compreender as preferências de compra e a utilização dos diferentes canais de venda.
* **Estratégias comerciais:** investigar padrões de consumo e oportunidades de vendas.
* **Relacionamento com clientes:** utilizar informações sobre recência e frequência de compra para apoiar ações de retenção.
* **Tomada de decisão orientada por dados:** transformar informações de clientes em subsídios para o planejamento estratégico.

## 🚀 Como Executar o Projeto

Para visualizar o relatório, siga os passos abaixo:

1. Baixe ou clone este repositório.
2. Instale o Microsoft Power BI Desktop, caso ainda não esteja instalado.
3. Abra o arquivo `Analise de Marketing.pbix`.
4. Se necessário, atualize o caminho da fonte de dados para o arquivo `dados_marketing.csv`.
5. Atualize os dados no Power BI.
6. Explore as páginas e os filtros disponíveis no dashboard.

**Importante:** caso o arquivo CSV seja movido para outra pasta, pode ser necessário configurar novamente a origem dos dados no Power BI.
